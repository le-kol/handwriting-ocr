Объединить два существующих представления слов скана (текстовое recognized-text и табличное words-table) в единое, с приоритетом текстового представления. Табличное представление убрать.

Изменения текстового представления:
- Каждое слово в тексте получает визуальный индикатор статуса векторизации (векторизовано / не векторизовано), не меняющий текст самого слова.

Изменения панели редактирования выбранного слова (существующая draft-панель с текстом, координатами, Сохранить/Отмена):
- Добавить миниатюру векторного представления (существующий компонент WordCurveThumbnail), если слово векторизовано.
- Добавить кнопку "Векторизовать" для невекторизованного слова (переносится из убираемой таблицы, использует существующую логику handleVectorizeClick).
- Добавить кнопку "Удалить слово", вызывающую существующий DELETE endpoint. Удаление происходит сразу по клику, без диалога подтверждения. После успешного удаления: слово убирается из списка words и из текущей раскладки layoutLines; если удалённое слово было выбрано (draft) — панель редактирования закрывается.

Добавить кнопку пакетной векторизации "Векторизовать все слова" в панель управления раскладкой (рядом с существующей кнопкой "Сохранить порядок"), вызывающую существующий batch-endpoint. После успешного ответа — обновить words и раскладку данными из ответа (ответ уже содержит актуальный список слов, включая curvePoints).

Не входит в объём: изменения backend; изменения формата данных; 
подтверждение/undo для удаления.
