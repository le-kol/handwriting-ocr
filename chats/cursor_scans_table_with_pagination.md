Добавить отображение таблицы всех сканов, хранящихся в БД, с пагинацией и облегчёнными миниатюрами.

Backend:
- GET /api/Scans?page={page} — возвращает страницу сканов (только { id }) и общее количество сканов в БД. Размер страницы фиксированный, задаётся константой на сервере (30). Сортировка — по id по убыванию (новые сверху). Первая страница — page=1.
- GET /api/scans/{id}/thumbnail — уменьшенная версия изображения скана (максимальная сторона ~200px), формируется на лету через существующую зависимость SixLabors.ImageSharp, без сохранения на диск. Ответ включает заголовок Cache-Control для кэширования браузером. Ошибки (файл отсутствует/повреждён) обрабатываются по уже существующей карте (404 «Не найден файл» — тот же паттерн, что в фиче векторизации).

Frontend:
- Таблица сканов с миниатюрами через новый thumbnail-эндпоинт (не полноразмерный /image).
- Управление пагинацией (вперёд/назад), используя общее количество из ответа для определения последней страницы.
- При клике на строку — открытие скана в существующем редакторе, тем же способом, что при upload (тот же сброс состояния редактора).

Не входит в объём: настраиваемый размер страницы; предвычисление и хранение миниатюр на диске; дата загрузки; число слов на скан; удаление скана; поиск/фильтрация по сканам.
