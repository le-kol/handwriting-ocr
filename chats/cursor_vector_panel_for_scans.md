Добавить на экран работы со сканом отдельную панель просмотра всех уже векторизованных слов текущего скана одновременно, не накладываемую на изображение скана. Панель показывает миниатюры формы штрихов (по сохранённым кривым слова) для каждого векторизованного слова скана сразу, в порядке строк и позиций текущей раскладки, без необходимости выбирать слова по одному через клик. Миниатюры отображаются в собственной системе координат каждого слова (как существующая миниатюра в панели редактирования), а не в координатах скана. Клик по миниатюре выбирает то же слово, что и клик по слову в тексте или по рамке на изображении — открывается существующая панель редактирования этого слова без изменения её поведения.

Расположение: рабочая область по-прежнему делится на изображение скана слева и раскладку текста справа; правая часть дополнительно делится по высоте на распознанный текст сверху и панель векторов снизу, обе видны одновременно без прокрутки всей страницы. Левая часть с изображением скана и рамками слов не содержит наложенных кривых и не меняется. На узких экранах (мобильные устройства) правая часть целиком (текст, затем панель векторов) переносится под изображение скана, сохраняя порядок «текст → векторы».

Если в скане нет ни одного векторизованного слова, панель векторов не занимает место или показывает понятное пустое состояние без ложной геометрии. После одиночной или пакетной векторизации панель обновляется без перезагрузки. Существующие функции — миниатюра выбранного слова в панели редактирования, индикаторы статуса векторизации в тексте, кнопки «Векторизовать» / «Векторизовать все слова» / «Удалить слово», перетаскивание слов и сохранение раскладки — не входят в объём изменений и не должны регрессировать.

Не входит в объём: наложение кривых на изображение скана в координатах скана; изменения серверного API и формата данных слова; редактирование кривых вручную; настройка параметров векторизации (отдельная фича).

**Question:** Если в строке часть слов векторизована, а часть — нет, как миниатюры в панели векторов должны соотноситься с позициями слов в тексте? (FR-003)

Порядок «строки и позиции» в спецификации можно реализовать по-разному; без явного правила легко получить несовпадение с ожиданиями оператора и разные acceptance-тесты.

**Recommended:** Option A — сохранять разбиение на строки, но внутри строки показывать только миниатюры векторизованных слов без пустых слотов; это согласуется с требованием не показывать ложную геометрию и с edge case про невекторизованные слова.

| Option | Description |
|--------|-------------|
| A | Строки как в тексте: каждая строка раскладки — отдельная строка в панели; внутри строки только миниатюры векторизованных слов, без пустых слотов для невекторизованных |
| B | Полное зеркало текста: в каждой строке слоты на все позиции; у невекторизованных — пустое место или нейтральный маркер без геометрии штрихов |
| C | Одна непрерывная последовательность: все миниатюры в порядке чтения, без визуального разбиения на строки |
| Short | Свой короткий вариант (≤5 слов) |
