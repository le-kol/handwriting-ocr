# Quickstart: Inline-редактирование текста слова

**Feature**: `009-inline-word-text-edit`  
**Date**: 2026-08-18

Ручная проверка UI end-to-end. Backend не меняется.

## Prerequisites

1. PostgreSQL + API и Vite-клиент запущены (как в README).
2. Скан с распознанным текстом (несколько слов в `recognized-text`).
3. DevTools → Network (опционально) для проверки отсутствия лишних PUT/POST.

Контракт: [contracts/inline-word-text-ui.md](./contracts/inline-word-text-ui.md)  
Модель: [data-model.md](./data-model.md)

## 1. Выбор слова (регрессия)

1. Кликнуть слово в текстовом блоке.

**Ожидание**:
- Подсветка `.word.selected`, рамка на scan, панель с полем «Текст».
- Inline **не** активен (отображается текст, не input).

## 2. Вход в inline — второй клик

1. Кликнуть **то же** слово ещё раз (без смещения мыши).

**Ожидание**:
- Текст заменён на `<input>` с тем же содержимым.
- Курсор близко к месту клика.
- Панель открыта; поле «Текст» синхронизировано.

## 3. Inline save — Enter

1. Изменить текст в inline-input.
2. Нажать **Enter**.

**Ожидание**:
- Inline закрыт; span показывает новый текст.
- `saveStatus`: «Сохранено».
- Network: один PUT (или POST для id=0).
- Перезагрузить скан — текст сохранён.

## 4. Inline save — blur

1. Войти в inline; изменить текст.
2. Кликнуть вне input (например, toolbar).

**Ожидание**: как §3 (autosave + exit inline).

## 5. Exit без save — unchanged text

1. Войти в inline; **не** менять текст.
2. Enter или blur.

**Ожидание**:
- Inline закрыт.
- **Нет** запросов POST/PUT в Network.

## 6. Escape — отмена текста

1. Войти в inline; изменить текст (не сохранять).
2. **Escape**.

**Ожидание**:
- Inline закрыт; текст = последний сохранённый на сервере.
- Панель **открыта**; поле «Текст» = откат.
- Несохранённые coords рамки (если меняли до inline) **не** сброшены.

## 7. Ошибка autosave

1. Остановить API или симулировать 502.
2. Inline: изменить текст → Enter.

**Ожидание**:
- Inline **остаётся** активным; текст на месте.
- Сообщение «Ошибка сохранения: …».
3. Запустить API → Enter/blur снова → успех.

## 8. Выбор по рамке → inline одним кликом по тексту

1. Кликнуть рамку на scan (не текст).
2. Один клик по **этому** слову в тексте.

**Ожидание**: сразу inline (без второго клика по тексту).

## 9. Click vs drag (FR-017)

1. Выбрать слово.
2. Короткий клик без движения → inline (§2).

3. Выбрать слово снова; **перетащить** для DnD порядка (движение > ~5px).

**Ожидание**:
- Inline **не** открывается.
- Drag-and-drop порядка работает как раньше.

## 10. Inline + panel sync

1. В inline менять текст посимвольно.

**Ожидание**: поле «Текст» в панели обновляется синхронно.

2. Закрыть inline без изменений; менять **только** поле «Текст» в панели.

**Ожидание**: autosave **не** срабатывает до «Сохранить».

## 11. Отмена во время inline

1. Войти в inline; изменить текст.
2. **«Отмена»** в панели.

**Ожидание**:
- Inline закрыт; панель закрыта.
- Текст и coords откат к server state.
