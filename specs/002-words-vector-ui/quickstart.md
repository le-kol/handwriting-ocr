# Quickstart: Отображение и векторизация слов на клиенте

**Feature**: `002-words-vector-ui`  
**Date**: 2026-08-11

Ручная проверка UI end-to-end. Предполагается, что серверная фича `001-word-stroke-vector` уже работает (колонка `curve_points`, `POST …/vectorize`).

## Prerequisites

1. PostgreSQL с применённым Liquibase (включая changeset `curve_points` из 001).
2. Запущены API (Kestrel) и Vite-клиент (или полный SpaProxy) — как в корневом README.
3. Есть скан с распознанными словами (загрузка + «Распознать»).

Контракты: [contracts/words-list-ui.md](./contracts/words-list-ui.md), upstream [vectorize-word.md](../001-word-stroke-vector/contracts/vectorize-word.md).  
Модель UI: [data-model.md](./data-model.md).

## 1. Список слов и статусы

1. Открыть приложение, выбрать/загрузить скан, дождаться слов (recognize или уже сохранённые).
2. Найти секцию списка/таблицы слов (не путать с раскладкой строк для drag-and-drop).

**Ожидание**:
- Для каждого слова видны текст и статус «Не векторизовано» (если ещё не вызывали vectorize).
- Миниатюры нет у невекторизованных.
- Изображение скана и рамки слов работают как раньше.

## 2. Векторизация одного слова

1. У слова с `id > 0` нажать «Векторизовать».
2. Дождаться ответа (кнопка этого слова недоступна на время запроса).

**Ожидание**:
- Успех: статус → «Векторизовано»; появляется миниатюра формы штрихов.
- Миниатюра **не** нарисована поверх картинки скана.
- Остальные слова без изменений.

При необходимости сверить с API:

```http
GET /api/Scans/{scanId}/words
```

у того же `wordId` должен быть непустой `curvePoints`.

## 3. Собственная система координат миниатюры

1. Сравнить миниатюру с формой штрихов слова (визуально).
2. Убедиться, что path умещается в ячейке превью и не совпадает по размещению с рамкой на скане.

**Ожидание**: превью читаемо; нет попытки «попасть» в координаты скана.

## 4. Повторная векторизация

1. Снова нажать «Векторизовать» у того же слова.
2. Дождаться успеха.

**Ожидание**: одна строка слова; миниатюра обновлена; дубликатов строки нет.

## 5. Ошибка векторизации

Варианты (достаточно одного):
- временно недоступен файл скана / вызвать для несуществующего wordId через DevTools; или
- слово с заведомо пустой/битой областью (если есть в тестовых данных).

**Ожидание**:
- Понятное текстовое сообщение (RU).
- Если раньше была миниатюра — она остаётся; статус не сбрасывается в «пусто» из-за ошибки.

## 6. Смена скана / пустой список

1. Выбрать другой скан или скан без слов.

**Ожидание**: список соответствует новому скану; нет «призраков» слов предыдущего; пустой скан — понястое пустое состояние.
