# Data Model: Отображение и векторизация слов на клиенте

**Feature**: `002-words-vector-ui`  
**Date**: 2026-08-11

Клиент не вводит новых таблиц БД. Модель — расширение UI/TypeScript-представления уже существующей сущности Word и локального состояния экрана.

## Entities (client view)

### Word (клиентский тип, расширяется)

Зеркало серверного JSON (camelCase).

| Field | Type | Notes |
|-------|------|-------|
| id | number | 0 = несохранённый черновик |
| scanId | number | Владелец-скан |
| text | string | Текст слова |
| x1..y4 | number × 8 | Рамка на **скане** (для оверлея; не для миниатюры вектора) |
| orderIndex | number | Порядок в скане |
| lineIndex | number | Номер строки |
| **curvePoints** | **`number[][][] \| null \| undefined`** | **NEW на клиенте** — `[кривая][точка 0..3][x\|y]` в СК фрагмента |

#### Правила статуса векторизации (UI)

| Условие | Статус UI | Миниатюра |
|---------|-----------|-----------|
| `curvePoints` отсутствует / `null` / `[]` | Не векторизовано | Нет |
| Есть ≥ 1 кривая, после валидации ≥ 1 валидная | Векторизовано | SVG по валидным кривым |
| Массив есть, но все кривые невалидны | Не векторизовано (или «данные повреждены» без падения) | Нет |

Валидная кривая: ровно 4 точки; каждая точка — массив/кортеж из 2 конечных `number`.

#### Связь с сервером

- Чтение: элемент массива `GET /api/Scans/{id}/words`.
- После vectorize: тело `200` того же контракта Word (см. `001` / [contracts/words-list-ui.md](./contracts/words-list-ui.md)).

Координаты `curvePoints` **не** смешиваются с `x1..y4`.

### UI state (экран App)

| State | Type (логически) | Назначение |
|-------|------------------|------------|
| words | `Word[] \| null` | Список слов текущего скана (`null` = ещё не загружены / сброшены) |
| layoutLines | `Word[][] \| null` | Локальная раскладка (как сейчас); при update `curvePoints` синхронизировать те же id |
| vectorizingWordId | `number \| null` | Id слова с активным POST vectorize |
| vectorizeStatus / error | `string \| null` | Сообщение успеха/ошибки для оператора (RU) |

#### State transitions (векторизация в UI)

```text
[idle, word без curvePoints]
  --(клик «Векторизовать»)--> [vectorizingWordId = id]
  --(200 + Word)-------------> [words[i] = response; idle; статус «векторизовано» + миниатюра]
  --(!ok / network)----------> [idle; показать text ошибки; words[i] без изменений]

[idle, word с curvePoints]
  --(повторный vectorize 200)-> [curvePoints заменены целиком в words[i]]
```

Черновик `id === 0`: переход в vectorizing **недоступен**.

## Out of scope for this model

- Новые колонки/таблицы PostgreSQL.
- Модель редактирования контрольных точек.
- Batch-состояние «векторизовать все».
- Геометрический mapping фрагмент → скан.
