# Quickstart: Вставка слова на новую строку через drag-and-drop

**Feature**: `007-dnd-new-line-gaps`  
**Date**: 2026-08-17

Ручная проверка UI end-to-end. Backend не меняется.

## Prerequisites

1. PostgreSQL + API и Vite-клиент запущены (как в README).
2. Скан с **минимум тремя строками** распознанного текста (для проверки gap между строками).
3. Дополнительно: скан с **одной строкой** (edge case).

Контракт: [contracts/dnd-line-gap-ui.md](./contracts/dnd-line-gap-ui.md)  
Модель: [data-model.md](./data-model.md)

## 1. Gap над первой строкой

1. Открыть скан с несколькими строками.
2. Перетащить слово из середины документа в **зону над первой строкой** (навести до появления горизонтальной линии).
3. Отпустить.

**Ожидание**:
- Слово на **отдельной первой строке**; остальные строки ниже в прежнем порядке.
- Запросов к API нет.
- Кнопка «Сохранить порядок» становится активной.

## 2. Gap между строками

1. Перетащить слово из строки 2 в gap **между строками 1 и 2**.
2. Отпустить.

**Ожидание**:
- Слово на **новой строке между** строкой 1 и бывшей строкой 2.
- Слова в нетронутых строках не меняют порядок внутри строки.
- При drag-over подсвечена **только одна** gap-зона.

## 3. Gap под последней строкой

1. Перетащить слово в зону **под последней строкой**.
2. Отпустить.

**Ожидание**:
- Слово на **новой последней строке** (одиночное или первое на этой строке).

## 4. Сохранение порядка

1. После одного из gap-drop нажать **«Сохранить порядок»**.

**Ожидание**:
- «Порядок сохранён».
- Перезагрузить страницу / заново открыть скан — раскладка с новыми строками сохранена.

2. (Опционально) DevTools → Network: body PUT layout содержит отдельные массивы для однословных строк.

## 5. Регрессия: drop на слово

1. Перетащить слово и отпустить **на другое слово** (не на gap).

**Ожидание**:
- Слово вставлено **перед** целевым словом в той же строке.
- Подсветка `.word.drop-target` на слове при drag-over (не gap).

2. Drop на **первое слово** строки.

**Ожидание**: вставка в **начало** строки.

## 6. Регрессия: drop на строку

1. Перетащить слово и отпустить на **пустую область строки** (padding `<p>`, не на слово и не на gap).

**Ожидание**:
- Слово в **конце** этой строки.

## 7. Одна строка в документе

1. Открыть скан с одной строкой (или временно оставить одну строку после правок).

**Ожидание**:
- Gap **над** и **под** строкой работают.
- Gap **между** строками отсутствует (N=1 → только insertAt 0 и 1).

## 8. Отмена и drag end

1. Начать drag, навести на gap (линия видна), отпустить **вне** текста / нажать Esc (dragEnd).

**Ожидание**: подсветка gap сброшена; layout не менялся.

2. Изменить layout через gap → **Отмена** в панели редактирования.

**Ожидание**: раскладка восстановлена с сервера.

## 9. Черновик id=0 (если есть)

1. «Добавить слово» → перетащить черновик в gap.

**Ожидание**: DnD работает локально.

2. «Сохранить порядок» без сохранения черновика.

**Ожидание**: «Сначала сохраните новое слово» — без изменений.
