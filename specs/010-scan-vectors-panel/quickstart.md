# Quickstart: Панель просмотра всех векторизованных слов скана

**Feature**: `010-scan-vectors-panel`  
**Date**: 2026-08-20

Ручная проверка UI end-to-end. Предполагается: фичи `002`–`004` (миниатюра, batch, единый текст) уже в клиенте.

## Prerequisites

1. PostgreSQL + Liquibase; API и Vite-клиент запущены (как в README).
2. Скан с распознанными словами; для полного сценария — часть слов векторизована, часть — нет.

Контракт: [contracts/scan-vectors-panel-ui.md](./contracts/scan-vectors-panel-ui.md)  
Модель: [data-model.md](./data-model.md)

## 1. Раскладка экрана (desktop)

1. Открыть скан на viewport ≥ 1024×768.
2. Не прокручивать всю страницу.

**Ожидание**:
- Слева изображение скана с рамками, **без** кривых на изображении.
- Справа сверху — текстовая раскладка с toolbar.
- Справа снизу — **панель векторов**; обе секции видны в правой колонке.
- При длинном тексте/многих слотах — прокрутка **внутри** секции, не скрытие второй секции за пределами страницы.

## 2. Зеркало раскладки

1. Открыть скан: несколько строк, смесь векторизованных и невекторизованных слов.

**Ожидание**:
- Число строк в панели = число строк в тексте.
- В каждой строке число слотов = число слов в строке текста.
- Миниатюры только у векторизованных; у невекторизованных — пустой/нейтральный слот без кривой.
- Горизонтальное соответствие позиций: миниатюра на той же позиции, что слово в строке текста.

## 3. Пустое состояние (нет векторизованных)

1. Открыть скан, где **ни одно** слово векторизовано.

**Ожидание**:
- Панель векторов **видна**.
- Зеркало всех строк и позиций; все слоты пустые/нейтральные.
- Нет «сломанной» геометрии и нет впечатления, что панель отсутствует.

## 4. Выбор слова через панель

1. Кликнуть **миниатюру** векторизованного слова в панели.

**Ожидание**: слово выбрано в тексте, рамка на скане, открыта панель редактирования с корректным содержимым.

2. Кликнуть **пустой/нейтральный слот** невекторизованного слова.

**Ожидание**: тот же результат выбора, что клик по слову в тексте.

3. Слот выбранного слова в панели визуально выделен (как `.word.selected`).

## 5. Миниатюра vs editor

1. Выбрать векторизованное слово через панель.

**Ожидание**: миниатюра в слоте панели визуально согласна с миниатюрой в панели редактирования (та же логика СК фрагмента).

## 6. Обновление после векторизации

1. Выбрать невекторизованное слово → «Векторизовать» в editor.
2. Дождаться успеха **без** перезагрузки страницы.

**Ожидание**: в панели векторов в том же слоте появляется миниатюра.

3. «Векторизовать все слова» для оставшихся.

**Ожидание**: все соответствующие слоты показывают миниатюры; порядок = раскладка.

## 7. DnD и удаление

1. Перетащить векторизованное слово в другую позицию (не сохранять).

**Ожидание**: слоты в панели следуют новому порядку.

2. Удалить векторизованное выбранное слово.

**Ожидание**: слот пропадает; editor закрыт; текст обновлён.

## 8. Мобильная раскладка

1. Сузить окно &lt; 900px.

**Ожидание**: порядок блоков сверху вниз — скан, текст, панель векторов.

## 9. Регрессия

Проверить без новых дефектов: индикаторы в тексте, save layout, inline edit, frame drag, recognize, delete scan.

## 10. Скан без слов

1. Скан без слов (если доступен).

**Ожидание**: панель без строк слотов; UI не падает.
