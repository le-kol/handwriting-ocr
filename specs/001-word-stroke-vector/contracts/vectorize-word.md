# Contract: POST vectorize word

**Feature**: `001-word-stroke-vector`  
**Date**: 2026-08-11

## Endpoint

```http
POST /api/Scans/{id}/words/{wordId}/vectorize
```

| Parameter | In | Type | Description |
|-----------|----|------|-------------|
| `id` | path | int | Id скана |
| `wordId` | path | int | Id слова |

**Body**: none (отступ и погрешность — из `WordVectorization` в конфигурации сервера).

**Content-Type ответа (успех)**: `application/json`  
**Content-Type ответа (ошибка)**: `text/plain` (строка на русском), без ProblemDetails.

## Success

**200 OK** — тело: объект слова после сохранения вектора (тот же контракт, что у элементов `GET /api/Scans/{id}/words`, плюс `curvePoints`).

```json
{
  "id": 42,
  "scanId": 7,
  "text": "пример",
  "x1": 10.0,
  "y1": 20.0,
  "x2": 110.0,
  "y2": 18.0,
  "x3": 112.0,
  "y3": 60.0,
  "x4": 12.0,
  "y4": 62.0,
  "orderIndex": 3,
  "lineIndex": 1,
  "curvePoints": [
    [
      [1.0, 2.0],
      [3.5, 2.2],
      [6.0, 8.0],
      [9.0, 8.1]
    ]
  ]
}
```

Инварианты `curvePoints` при 200:

- не `null` и не пустой массив верхнего уровня;
- у каждой кривой ровно 4 точки;
- у каждой точки ровно 2 числа `(x, y)`;
- координаты относительно выровненного фрагмента.

Повторный успешный вызов **заменяет** прежний `curvePoints`.

## Error responses

| Status | Когда | Пример тела |
|--------|-------|-------------|
| 404 | Скан не найден | `Не найдена запись в БД` |
| 404 | Слово не найдено или не принадлежит скану | `Слово не найдено` |
| 404 | Файл скана отсутствует на диске | `Не найден файл` |
| 400 | Вырожденная рамка / рамка не пересекается с изображением / не удалось выделить штрихи / повреждённое изображение | русский текст причины |
| 503 | Не задана или невалидна конфигурация `WordVectorization` | русский текст |

При любой ошибке значение `curve_points` в БД **не** должно становиться пустым/частичным: либо без UPDATE, либо откат транзакции.

## Related read contract (совместимость)

`GET /api/Scans/{id}/words` после миграции MAY включать `curvePoints: null` или массив для уже векторизованных слов. Остальные поля без изменений. Клиент, игнорирующий неизвестные поля, остаётся совместим.

## Out of scope

- Query/body параметры отступа и tolerance.
- Отдельный ресурс `/api/Words/...`.
- Batch-векторизация всех слов скана.
- UI-контракт React.
