# Quickstart: Редактирование рамки слова на скане через drag-and-drop

**Feature**: `008-dnd-word-frame-edit`  
**Date**: 2026-08-17

Ручная проверка UI end-to-end. Backend не меняется.

## Prerequisites

1. PostgreSQL + API и Vite-клиент запущены (как в README).
2. Скан с **несколькими словами** и видимыми рамками (после распознавания).
3. Желательно: скан с **перекрывающимися** или близкими рамками (для §6).

Контракт: [contracts/frame-drag-ui.md](./contracts/frame-drag-ui.md)  
Модель: [data-model.md](./data-model.md)

## 1. Выбор без случайного сдвига

1. Убедиться, что слово **не** выбрано.
2. Нажать на рамку слова на scan и, **не отпуская**, провести мышь.
3. Отпустить.

**Ожидание**:
- Слово **выбрано** (синяя рамка, маркеры на углах, панель редактора).
- Координаты x1–y4 **не изменились**.
- Запросов к API нет.

## 2. Перемещение всей рамки

1. Выбрать слово (клик по рамке или по слову в тексте).
2. Нажать на **внутреннюю область** синей рамки (не на угол).
3. Перетащить на новое место; отпустить.

**Ожидание**:
- Все четыре вершины сдвинулись одинаково; форма сохранена.
- Поля x1–y4 в панели обновлялись **во время** drag.
- После отпускания — без API.

4. Нажать **«Сохранить»**.

**Ожидание**: «Сохранено»; перезагрузить скан — рамка на новом месте.

## 3. Правка угла

1. Выбрать слово.
2. Перетащить **один** угловой маркер.
3. Отпустить.

**Ожидание**:
- Изменилась только одна вершина; остальные три на месте.
- Соответствующие поля x/i, y/i обновлены.

4. **«Сохранить»** → перезагрузка → форма рамки сохранена.

## 4. Приоритет угла над перемещением

1. Выбрать слово.
2. Начать drag **с углового маркера**.

**Ожидание**: двигается угол, **не** вся рамка целиком.

## 5. Числовое редактирование (регрессия)

1. Выбрать слово; изменить **x1** в панели.

**Ожидание**: рамка на scan сразу сдвинулась.

2. Перетащить рамку на scan.

**Ожидание**: поле x1 (и остальные) синхронизированы.

## 6. Перекрывающиеся рамки

1. Кликнуть в область пересечения двух рамок (если есть).

**Ожидание**: выбрано слово с **меньшим orderIndex** (раньше в порядке чтения).

## 7. Новое слово — начальная рамка

1. **«Добавить слово»**.

**Ожидание**:
- На scan — небольшой прямоугольник **по центру** изображения с маркерами.
- x1–y4 не все нули.

2. Перетащить углы; ввести текст; **«Сохранить»**.

**Ожидание**: слово создано; после перезагрузки рамка на заданном месте.

## 8. Отмена

1. Выбрать слово; перетащить рамку (не сохранять).
2. **«Отмена»**.

**Ожидание**: рамка вернулась к последним **сохранённым** координатам; панель закрыта или draft сброшен.

## 9. Регрессия: DnD порядка в тексте

1. Перетащить слово в recognized-text (на слово, строку, gap-зону).

**Ожидание**: поведение как до фичи; порядок меняется локально.

2. **«Сохранить порядок»** — успех.

3. Убедиться, что frame drag на scan **не** стартовал при text DnD.

## 10. Регрессия: layout vs coords

1. Изменить рамку черновиком (не сохранять слово).
2. **«Сохранить порядок»** (без «Сохранить» слова).

**Ожидание**: на сервер ушла только раскладка; координаты слова на сервере **не** изменились.
